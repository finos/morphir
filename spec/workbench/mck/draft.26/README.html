Contract

This directory contains independently authored raw inputs and fixed expected observations for exact 0.1.0-draft.26. Read the normative contract for operation shapes, semantic limits, binary fixture provenance and scope.

Inventory

cases.json is the authoritative byte-hashed corpus. It covers all nine JSON/Ion text/Ion binary transcode directions, rich values and exact extension bytes, malformed sources, limits, and exact/approximate typed-value comparison with independent mismatch paths. The combined kit requires both operations. An adapter claiming only one operation can qualify the transcode kit or comparison kit; unsupported records always prevent combined qualification. Each subset preserves its canonical case IDs, input bytes and fixed expected results. Expected results are never sent to adapters. Production-adapter qualification and report rechecking use the existing shared Rust runner.
