Scope

Exact MCK version 0.1.0-draft.20, JSON operation validate-native-policy-boundary. Original raw request/reply bytes stay opaque to the shared runner. The adapter chooses explicit native 0.2.0-draft.2 decoding. Request success is frameAccepted; reply success retains replyAccepted and correlated operation or explicit error effect. The input kind is request or reply. Reply input requires expectedOperation and expectedSession. Optional compact prefix generation retains the frozen exact-count semantics.

The 75 fixed cases are parent-owned, authored independently of implementation output. There is one shared Rust runner and checker. Inputs never include expected results or case identifiers sent to the adapter.

Evidence limits

Corpus and projection validation proves bounded infrastructure shape. Adapter comparison proves agreement with fixed observations. Saved-report checking binds exact corpus bytes and recomputes verdicts. Controlled callers and dependencies do not prove framework provenance, worker isolation or OS integration. Actual processes and each packaged OS/architecture need separate evidence. Earlier contracts and kits remain frozen.
