Scope

This exact profile records local Scheme worksheet observations. It adds no remote method, execution authority, persistent interpreter session or generated-backend execution. Browser and desktop clients may share it. Each explicit run creates one fresh bounded runtime; definitions remain available only within that run.

Typed means a validated existing execution.Value. It does not imply static Scheme type inference. Reuse the frozen terminal outcome payload and value schema; do not extend their variants or invent Scheme custom constructors. The request and report schemas describe structure. This document defines additional semantic and UTF-16 bounds.

Captured source

A request has exactly {profile,contractVersion,source}. Profile is morphir/workbench/worksheet; contractVersion is exactly 0.1.0-draft.1. A source has exactly {id,revision,text}. Capture all three before asynchronous work. The logical ID grants no filesystem access.

{"profile":"morphir/workbench/worksheet","contractVersion":"0.1.0-draft.1","source":{"id":"worksheet-source","revision":4,"text":"(+ 1 2)"}}

The source ID contains 1–128 UTF-16 units and no C0/C1 control codepoints. Revision is a mathematically integral JSON number from 0 through 2,147,483,647. A fractional number that underflows a floating-point parser is still fractional and rejects. Text and JSON keys must be well-formed UTF-16; do not silently replace unmatched surrogates. Every edit changes the revision. If the revision counter is exhausted, allocate a new ID before resetting it.

Report and typed values

A report has exactly the request's profile/version/source plus observations, completion and diagnostic. Every observation has exactly {id,range,expression,preview,outcome}. The source capture is unchanged; expression is the exact captured source slice, including authored quotes and spelling. Preview is the bounded Scheme value renderer, never evidence for a typed returned value.

Scheme valueTyped observation
Exact integer, boolean, unit, text, characterExisting Integer, Boolean, Unit, Text and Character. Preserve UTF-16 units.
Finite inexact realExisting Float64 with exact bits, including signed zero.
Proper list, vector, recordExisting Sequence, Product and Record, recursively, if every child is representable. Record fields are compared by name. No homogeneous static type is inferred.
Nonintegral rational, symbol, dotted pair, procedure, native function, IR wrapper or unknown tagged valueA failed typed projection with code worksheet.value_unsupported and message This Scheme value has no portable worksheet representation. Keep the original bounded preview and continue subsequent forms. Never cast its printed representation into Text.

Each outcome reuses existing Returned, ModelError, Failed or Cancelled payloads. An actual recognized model error uses its existing variant; ordinary Scheme errors are failures. A structural ModelError row is a completed observation and permits returned-unit completion with null diagnostic when no other row requires a diagnostic. The current local Scheme language exposes no recognized SDK ModelError constructor, so validation-only evidence does not claim ModelError can be produced by a Scheme program. Returned values in this profile are limited to the listed portable representations. An unrepresentable child makes the whole row's typed projection unavailable.

Coordinates and identities

Ranges have exactly {start,end} and use zero-based half-open UTF-16 offsets over the captured source. A form range is nonempty, ordered, nonoverlapping and excludes surrounding trivia. It never splits a surrogate pair. CRLF remains two captured units. The implementation must convert scalar-index parser offsets explicitly; neither pretty-print length nor the next form's start defines a form's end.

IDs are exactly form-0, form-1 and so on in top-level source order. They are scoped to the capture. The production validator reparses the captured source and reconciles the authoritative form inventory, exact ranges and slices. A supplied report cannot add, drop or reorder observations while claiming complete evaluation. A stopped run contains only its permitted prefix.

Read diagnostics use an actual zero-width error offset, including EOF, when the parser provides one. Some reader errors, such as unsupported quasiquotation, provide no position; those use a null range. Evaluate/project diagnostics identify whole forms. Transport diagnostics use null range. The editor must reconcile the full capture before marks or reveal, and map captured CRLF offsets if its document normalizes newlines.

Completion and diagnostics

Completion is an existing terminal payload restricted to Returned(Unit), Failed or Cancelled. Returned(Unit) means the evaluator reached the end; individual unavailable projections may still exist. Diagnostic is null or exactly {stage,range}, where stage is read, evaluate, project or transport. Failure details live only in the existing terminal descriptor.

ConditionRequired evidence
Empty/comments-only sourceNo observations, returned unit, null diagnostic.
Read failureParse the complete source before any evaluation. No rows; completion failure code worksheet.read_failed; read diagnostic with actual zero-width location or null only when unavailable. Preserve bounded actual error_message.
Runtime failure/limitRetain completed rows and append the failing row with empty preview. Stop the suffix. Completion equals that row's failure; diagnostic evaluate identifies it. Codes are worksheet.evaluation_failed and worksheet.runtime_limit.
Projection unavailableThe row fails with worksheet.value_unsupported but the runtime continues. On returned-unit completion, diagnostic project identifies the first unavailable row. A later fatal runtime error overrides it.
Output budget exhaustedRetain only fitting prefix rows. Completion fails with worksheet.output_limit. Diagnostic project identifies the current unretained form. Reserve a bounded captured failure envelope before running.
Worker crash/deadlineNo invented rows; completion fails with worksheet.worker_failed or worksheet.timeout; diagnostic transport/null.
User cancellationThe owner terminates its worker. Completion cancelled and diagnostic transport/null. Without streaming there are no claimed partial rows. This is not proof that no form ran.

All read/evaluation/projection failure descriptors use the existing evaluate stage. Transport descriptors may use an appropriate existing primary stage. Codes and messages remain subject to existing terminal invariants.

RuntimeExisting Scheme defaults: 1,000,000 evaluation steps, depth 256 and 100,000 environment frames. One runtime budget covers all forms in the captured run.

The whole serialized report includes the capture and exact expression slices. Reserve a valid failure envelope before evaluation; count encoded row bytes incrementally. Preview generation and typed projection must bound traversal before expanding shared child occurrences. A compact runtime graph must not expand without limit before the report/value guards run. A row whose expanded representation exceeds the available budget produces worksheet.output_limit with no row retained for that form. Refuse before starting if even that reserved reply cannot fit. The completion Unit is not charged against the aggregate row-value budget. Worksheet terminal validation reuses frozen semantics with caller-owned aggregate and document bounds; the frozen outcome/value entry points retain their independent 1 MiB limits. These are acceptance bounds, not a claim that the parser streams arbitrary input.

Validation order

Check raw request/report byte bounds, then duplicate-aware JSON syntax and well-formed strings, then closed shape/profile/version. Validate the request's source identity/revision/text. For supplied evidence, compare its capture to the request before range/slice reconciliation. Then check form identities, exact UTF-16 ranges and source slices, typed terminals/shared budgets, completion and diagnostic consistency.

Stable boundary rejection codes are worksheet.invalid_json, worksheet.invalid_request, worksheet.input_limit, worksheet.invalid_report, worksheet.source_mismatch, worksheet.invalid_range, worksheet.invalid_identity and worksheet.output_limit. They are not runtime terminal failures. A present malformed report never falls back to legacy strings or a success flag.

Qualification

MCK draft 27 separates actual production worksheet evaluation from supplied-report validation. A structurally valid supplied cancellation proves neither live worker termination nor host lifecycle. Browser and packaged Proton need separate runtime receipts, exact executable/source identity and actual editor/download interactions as applicable.

This profile changes no frozen execution value/outcome, connected protocol v1 or native/HTTP mapping. It does not authorize daemon evaluation, package publication or durable recovery.
