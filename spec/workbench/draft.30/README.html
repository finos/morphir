Scope

This exact draft reserves the connected MCK operation names model-originals-server and model-originals-client. It defines their capability selection. The parent repository owns the shared Rust runner, independent expectations and schemas. Implementations participate through actual adapters.

This is a bounded allocation preparation. Corpus, report, observation and adapter contracts still require coherent implementation and review. This page and its capability schema do not advertise a complete runnable kit, qualified producer, default profile or successful campaign.

Capabilities

The capability schema describes a closed document. suite is exactly workbench; contractVersion is exactly the canonical SemVer string 0.1.0-draft.30. Leading v, build metadata, adjacent drafts and nearby releases are refused.

Empty operations, duplicates, unknown names and historical operations are refused. This document does not specify the transport correlation member of a negotiation reply.

Identity limits

For this draft only, binding and language each contain 1 to 128 UTF-8 bytes after JSON string decoding. Text is compared without Unicode normalization. ASCII 128, 64 copies of U+00E9 and 32 copies of U+1F4AB each occupy 128 bytes. Adding one ASCII byte refuses each boundary.

JSON Schema maxLength counts Unicode code points. Its 128-code-point bound is necessary but does not prove the UTF-8 byte bound. The shared Rust capability decoder enforces the byte rule. Schema validation alone is insufficient. Older exact drafts retain their existing identity and empty-capability behavior.
