## Historical extension design

The
[WASM extension components source](https://github.com/finos/morphir/blob/main/docs/spec/webassembly/wasm-components.md)
records an earlier WIT-based extension ABI. It is excluded from the published
site. Current extensions use Extism plus MEP JSON-RPC, not that component
interface.
