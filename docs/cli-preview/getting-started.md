# Getting Started with CLI Preview (Archived)

:::caution Archived
This guide described installing a Go-based Morphir CLI from finos/morphir. That tooling now lives in **[finos/morphir-go](https://github.com/finos/morphir-go)**.
:::

## Current documentation

- **Morphir Go:** [Morphir Go](../getting-started/morphir-go-preview.md) and [finos/morphir-go](https://github.com/finos/morphir-go)
- **Rust Morphir CLI (this repo):** [Morphir CLI](../getting-started/morphir-cli.md)
- **Archived overview:** [CLI Preview (Archived)](index.md)

The install scripts, `go install github.com/finos/morphir/cmd/morphir`, and WIT examples on earlier versions of this page applied to the Go CLI when it was hosted in finos/morphir. They are not valid for the Rust CLI shipped from this repository today.
