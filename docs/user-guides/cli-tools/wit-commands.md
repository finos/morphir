# WIT Commands (Archived)

:::caution Archived
The `morphir wit` command family is part of the **Morphir Go CLI**, not the Rust CLI shipped from finos/morphir. Current WIT documentation and development live in **[finos/morphir-go](https://github.com/finos/morphir-go)**.
:::

## Current documentation

- [Morphir Go](/docs/getting-started/morphir-go-preview) — ownership and install pointers
- [finos/morphir-go](https://github.com/finos/morphir-go) — Go CLI, WIT pipeline, and Go backends
- [Morphir CLI](/docs/getting-started/morphir-cli) — Rust CLI from this repository
- [CLI Preview (Archived)](/docs/cli-preview/) — archived Go CLI preview pages formerly hosted here

Do not treat the former `morphir wit make` / `morphir wit gen` / `morphir wit build` examples that lived on this page as commands for the Rust `morphir` binary in finos/morphir.
