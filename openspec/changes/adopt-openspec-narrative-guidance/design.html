Context

See the proposal for motivation. Morphir already uses html-design and an installer-owned format-2 lock. Mission Control published tools-v0.1.2 from 17305df4d80f01d0db3e584976ee0423a2cc3574; its release verification passed ten jobs, archive hashes, attestations and a fresh Windows consumer install.

Goals and non-goals

Contributors should receive the published shared instructions together with Morphir's authoring policy. Keep shared files reproducible from the released binary and preserve the existing project context. This adoption changes no runtime contracts, language implementations or other proposals.

Decisions

TOOL-1. Install the published bundle

A contributor updates the tools pin from 0.1.0 to 0.1.2, installs it through mise, then runs mission-control-tools openspec install. The installer writes the schema, templates and lock from its embedded bundle. This uses the existing release path instead of a local build or edits to generated snapshots. If a managed file has local edits, the installer refuses the update; inspect and preserve those edits before retrying. Bundle verification catches a pin update without a matching installation.

DOCS-1. Keep Morphir policy outside generated files

When that contributor requests design instructions, OpenSpec combines the shared narrative guidance with the existing project context and the new artifact rules in openspec/config.yaml. The developer guide illustrates an acquisition journey as an authoring example, not an implemented feature. Keeping those examples and rules local avoids changing the shared snapshot for Morphir policy. skip_specs: true records that this adoption introduces no behavior contract; inventing a runtime requirement would misrepresent its scope.

Migration plan

Run the installer, verify instructions and mise run openspec:verify, check formatting and submit the scoped adoption PR. Parent review owns landing; leave this change unarchived for that review. Rollback restores the previous tools pin and matching installer-owned files together. Reverting only the pin would leave the bundle check failing. See the verification tasks.
