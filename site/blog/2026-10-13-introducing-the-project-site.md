The Morphir MoonBit project now has a site. It publishes the [documentation](../../docs/README.md),
the [architecture decision records](../../docs/adr/README.md), this blog, and the Morphir Workbench at
[Try Morphir](/try/).

The site is generated by MoonBit code in `apps/morphir-site`, with Rabbita rendering every page on the server.
Pages read without JavaScript; a small script adds search and a theme switch.

To write a post, read [Writing for the site](../../docs/WRITING_FOR_THE_SITE.md).
