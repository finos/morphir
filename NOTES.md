# finos/morphir — repository notes

This file is a quick orientation for contributors and AI assistants.

## What this repo is

**finos/morphir** is the Morphir ecosystem **umbrella** repository. It hosts:

- Published documentation (`docs/`, `website/`)
- Specifications, compatibility kits and the delivery of the **Morphir CLI**, whose source is [finos/morphir-dotnet](https://github.com/finos/morphir-dotnet)
- **Ecosystem submodules** (`ecosystem/`)

## What this repo is not

This is **not** the Morphir Go project. Go-based Morphir tooling — including the WIT pipeline and Go code generation — lives in the sibling repository **[finos/morphir-go](https://github.com/finos/morphir-go)**.
